# Cláudio Victor

**Software Developer**

Welcome to my GitHub! Here you'll find my main projects in software development, including backend systems, REST APIs, full-stack web applications, mobile applications, and developer tools.

I'm a software developer interested in building practical solutions for real-world problems. My experience includes backend development with **PHP, Go, and Node.js**, frontend development with **JavaScript, React, HTML, CSS, and Bootstrap**, and mobile development with **Dart and Flutter**.

I'm also interested in software architecture and framework development. I've created **Slenix**, a PHP framework, and **Kite**, a Go framework, as part of my exploration of how web frameworks and developer tools work internally.

## 📌 Featured Projects

* **[Slenix](https://github.com/claudiovictors/slenix)** — PHP framework created by me for building web applications and backend systems. The project explores application architecture, routing, database integration, authentication, CLI tooling, and other common framework components.

* **[Kite](https://github.com/claudiovictors/kite)** — Go framework focused on building web applications and REST APIs. It explores HTTP handling, routing, middleware, authentication, database integration, and application structure in Go.

* **[Point of Sales](https://github.com/claudiovictors/point-of-sales)** — Business and point-of-sale system focused on products, sales, customers, employees, cash-register operations, and real-world business workflows.

* **[E-commerce](https://github.com/claudiovictors/e-commerce)** — E-commerce application focused on product management, customers, authentication, database integration, and business logic.

* **[Clinic API](https://github.com/claudiovictors/clinic-api)** — REST API for clinic-related workflows, including authentication, database persistence, HTTP communication, and business logic.

* **Event APIs** — REST APIs developed for event-related applications and workflows, with a focus on backend architecture, authentication, database integration, and API design.
